# BorneoWatch 🌲
A web-based prototype designed to visualize and track demo environmental metrics across East Kalimantan, Indonesia.

## 📌 Project Overview
Living in East Kalimantan, I am deeply aware of the environmental changes surrounding our rainforests. I built **BorneoWatch** as a personal project to explore how digital platforms can help communities map and report ecological signals. Since this is a concept prototype, all data, maps, and figures displayed are simulated demo content.

## 🛠️ Tech Stack & Learning Journey
This project represents my first step into modern web development. As a self-taught programmer with limited local tech mentorship, I utilized AI tools (like v0.dev and Antigravity AI) as my digital mentors to help me understand React/Next.js structures, fix layout bugs, and implement Tailwind CSS. 

Through this project, I learned how to:
- Structure a Next.js application and deploy it via Vercel.
- Integrate interactive frontend components and manage app states.
- Read, debug, and modify AI-assisted code to fit my design goals (e.g., implementing custom "Under Construction" states for unfinished demo features).
